Perso API 기본 도메인은?
	https://api.perso.ai/
다운로드 상대 경로를 결합하는 미디어 도메인은?
	https://portal-media.perso.ai/
Perso API 인증에 사용하는 HTTP 헤더 이름은?
	xp-api-key
작업 공간을 식별하는 정수 ID는?
	space_seq
업로드 파일 등록 후 발급되는 ID는?
	mediaSeq
생성 작업을 식별하는 ID는?
	projectSeq
내가 접근 가능한 Space 목록 조회 HTTP 메서드와 경로는?
	GET/portal/api/v1/spaces
파일 직접 업로드의 세 단계는?
	SAS발급 > Azure Blob PUT > audio/video 등록
Azure Blob PUT에서 반드시 필요한 Blob 형식 헤더는?
	x-ms-blob-type:BlockBlob
SAS 업로드 시 XP-API-KEY 헤더를 추가해야 하는가?
	X / SAS URL 자체 서명이 인증입니다.
STT 약어를 풀어 쓰고 기능을 설명하시오.
	speak to text , 음성을 텍스트로 변환
Audio Separation API가 분리하는 두 트랙은?
	목소리 , 배경음
언어별 지원 TTS 모델을 확인하는 응답 필드는?
	supportedTtsModels
자동 입력 언어 감지 코드로 쓰지만 번역 대상 코드로 쓸 수 없는 값은?
	auto

	result.startGenerateProjectidList
프로젝트 진행률 응답에서 완료 여부를 판단하는 필드는?
	ressult.progressReason
프로젝트 진행률 확인 시 권장 최소 폴링 간격은?
	5 초 이상

	/download-info

	all(.tar 아카이브)

	confirm_cost-true 명시 / 기존 projectSeq/작업 상태 확인
